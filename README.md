# NOVA — Jujutsu Kaisen Domain Engine

Real-time hand tracking and anime visual effects for Jujutsu Kaisen domain expansions.

## Quick Start

```bash
python -m http.server 8000
```
Open `http://localhost:8000` in your browser. (Windows: double-click `start.bat`).

## Controls

| Key | Action | Hand Sign |
| :---: | :--- | :--- |
| **`[1]`** | Infinite Void | Cross middle finger over index finger |
| **`[2]`** | Malevolent Shrine | Touch index fingertips together pointing up (roof gable) |
| **`[3]`** | Chimera Shadow Garden | Hook thumbs together, spread fingers like wings |
| **`[4]`** | Self-Embodiment of Perfection | Cup palms inward, weave fingers into a hollow cage |
| **`[R]`** | Hollow Purple | Blue & Red fusion into violet erasure projectile |
| **`[S]`** | Furnace: Fire Arrow | Blazing flame arrow detonation |
| **`[D]`** | Boogie Woogie | Clap hands together |
| **`[G]`** | Toggle Ghost Guide | Show alignment silhouette on camera |
| **`[M]`** | Toggle Audio | Mute / Unmute sound |
| **`[Space]`** | Dismiss Domain | Collapse active domain |
